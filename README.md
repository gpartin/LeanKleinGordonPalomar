# LeanKleinGordonPalomar

Palomar submission wrapper for three narrow C19 theorems extracted from the
[LeanKleinGordonDerivation](https://github.com/gpartin/LeanKleinGordonDerivation)
release.

Archived release: https://zenodo.org/records/24287570

The development proves that the stated face-and-edge cubic stencil has an
exactly isotropic quadratic moment with coefficient `12`, and bounds its
finite-spacing cosine symbol by an explicit quartic remainder.

It does not prove convergence of arbitrary nonlinear lattice trajectories, a
native massless carrier, a physical particle, or that LFM models nature.

Build with:

```text
lake update
lake build
lake comparator
```
